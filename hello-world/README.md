# ☕ Meus Primeiros Passos com Java

Bem-vindo ao meu repositório de estudos! Este espaço foi criado para documentar minha evolução na linguagem Java, desde o clássico "Hello World" até pequenos sistemas funcionais.

## 🚀 Desafio Atual: Calculadora de IMC

O primeiro exercício prático deste repositório é uma **Calculadora de Índice de Massa Corporal (IMC)**. O objetivo foi aplicar conceitos básicos de lógica de programação e sintaxe da linguagem.

### 🧠 Conceitos Aplicados:
* **Entrada de dados:** Uso da classe `Scanner` para interagir com o usuário via terminal.
* **Estruturas Condicionais:** Utilização de `if`, `else if` e `else` para classificar o resultado do IMC.
* **Operadores Lógicos:** Uso do operador `&&` (AND) para verificar faixas de valores.
* **Saída Formatada:** Uso do `System.out.printf` para limitar as casas decimais do resultado.
* **Métodos Estáticos:** Organização do código dividindo o `main` de funções auxiliares.
